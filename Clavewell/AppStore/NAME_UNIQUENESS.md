## Web search

A web search for the quoted string `"Clavewell"` on the same date did not find an app, game, company, or product using that exact name. The only hits were loose spellings of other words: a misspelling of the author James Clavell, and the surname of a fictional character in an unrelated amateur story. Neither is an App Store app named Clavewell.

## Names that were rejected

These were considered and not used, because an exact or obvious existing use turned up:

- Gleamwell — a dungeon object in the game *Children of Mana*, and also used by cleaning businesses.
- Nimwell — a pharmaceutical brand in India.
- Lumenwick — an existing browser game.
- Chromawell, Tallowwell, Parchwell, Glimwell, Brinkwell, Nockwell, Pleatwell — existing product, company, or trademark uses.
- Cairnwell, Bramblewick, Driftwell, Sparkwell, Shardwell, Huewell, and several other “well” compounds — exact App Store name matches.

Clavewell had no exact App Store match in the searches above.
